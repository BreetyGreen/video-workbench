# 在一台全新的 Mac 上用 Codex 接手本项目

适用对象：拿到这个仓库链接、电脑上还什么都没装的人。核对日期：2026-11-08。

全程大部分操作由 Codex 完成。你自己只需要做三类事：

- 安装 Codex 并登录
- 处理系统弹出的权限确认
- 在终端里自己填入属于你自己的 Key

## 一、先准备

| 项 | 说明 |
|---|---|
| Mac | 优先 M 系列芯片（Apple Silicon）。Intel 芯片的 Mac 没有验证过 |
| 磁盘 | 至少留 20 GB：工具和依赖约 3 GB，本机配音模型约 8 GB（可选），其余放素材和成片 |
| 网络 | 首次安装要下载 Python 依赖、ffmpeg、模型 |
| GitHub | 能打开仓库链接。如果仓库是私有的，需要仓库主人邀请你的 GitHub 账号 |
| 百炼 Key（可选） | 配音默认用本机 CosyVoice，不需要 Key。Key 只用于本机没装 CosyVoice 时的云端配音，以及更准的字幕时间对齐。要用就在阿里云百炼控制台用**你自己的**账号申请，不要用别人的 |
| 剪映专业版（可选） | 想生成剪映草稿再手动微调时才需要。从剪映官网下载 Mac 版，打开一次、新建一个空草稿再关掉 |
| 抖音账号 | 发布时由你自己在抖音 App 或 creator.douyin.com 上登录并点“发布” |

## 二、装 Codex 和 Git

1. 按 OpenAI 官网说明安装 Codex（桌面版或命令行版都可以），用你的账号登录。
2. 打开“终端”，执行下面的命令装 Git（会弹出系统安装窗口，点“安装”）：

```bash
xcode-select --install
```

## 三、让 Codex 完成首次安装

在 Codex 里新建一个会话，工作目录选你的用户目录。把下面这段话发给它：

> 把 https://github.com/BreetyGreen/video-workbench 克隆到 ~/video-workbench（用 main 分支），然后：
> 1. 按仓库里 AGENTS.md 的 First run 完成首次运行，跑一遍 `python3 scripts/doctor.py`；
> 2. 按 tools/sample-cut/README.md 的“一次性准备”装好样片剪辑工具；
> 3. 运行 tools/sample-cut/autopilot_setup.py（下载字体和 BGM 曲库、检查配音条件）；
> 4. 告诉我哪些已经就绪，哪些需要我自己做。
> 不要向我要任何 Key。

装的过程中，Mac 可能弹出这些确认，按需点“允许”：

- 安装 Homebrew 时会让你在终端里输入开机密码。这一步由你自己输入，Codex 不会也不应该替你输。
- 终端或 Codex 想访问“影片”“文稿”文件夹时，会弹出系统权限窗口。

## 四、填入你自己的 Key（需要云端配音或识别时）

**Key 不要发进 Codex 聊天，也不要写进仓库里的任何文件。** 在终端里自己执行：

```bash
echo 'export VIDEO_WORKBENCH_DASHSCOPE_API_KEY=这里换成你的Key' >> ~/.zshrc
source ~/.zshrc
```

然后重启 Codex，它就能在命令里用这个 Key，但看不到 Key 的内容。

不填 Key 也能用的部分：看素材选镜头、出片、加 BGM、生成剪映草稿、本机 CosyVoice 生成配音。

需要 Key 的部分：云端音色配音，以及配音后的逐字对齐（语音识别）。

## 五、本机配音和预制音色

配音默认用本机 CosyVoice。先对 Codex 说：

> 按 tools/cosyvoice/install.sh 安装本机 CosyVoice。

- 需要下载约 5 GB 模型，可能要一两个小时，中途断了重新运行会接着下载。
- **不用录音就能用**：首次安装时会自动装好一个内置音色包，有二十多个男声、女声（来自开源语音库 AISHELL-3，可以这样使用）。做视频时会按产品类型自动挑一个合适的音色，并带上带货语气。
- 想听听都有哪些音色，对 Codex 说：“给内置音色都做个试听”。
- 想固定用某个音色，就说“以后默认用 青年女声-高音1”；某一条想换，就说“这条用 成熟男声-中音1”。
- 也可以加自己的声音：录 5–15 秒，只有一个人说话，安静，不要背景音乐，把原话一字不差地写下来。然后对 Codex 说：“把 ~/Desktop/我的录音.m4a 加进音色库，名字叫 我的声音，这是我自己的声音，原话是：……，做个试听”。
- **自己加的音色只能是你自己的声音，或者本人书面同意的声音。** 从别人的视频、直播里截下来的声音，或者剪映等软件里的音色，都不行。

## 五（续）、我的BGM

`autopilot_setup.py` 会建好 `~/Movies/VideoWorkbench 我的BGM` 文件夹。把你喜欢的曲子（mp3、m4a 等）放进去，以后做视频会优先用这些曲子。

- 只放你有权使用的音乐，比如 Pixabay Music、Mixkit 的免费可商用曲子。需要署名的，在旁边放一个同名 .txt 写署名。
- 想用抖音热门音乐：发布时上传 `无BGM版`，在抖音里选音乐。

## 六、做视频：一句话，全自动

把拍好的素材放进一个文件夹，不用分类也不用改名，然后对 Codex 说：

> 用 ~/Movies/素材/<商品名> 做视频

Codex 会按 `tools/sample-cut/AUTOPILOT.md` 从头做到尾，中途不会问你任何问题：

- 自己归类镜头、挑镜头
- 从画面里读包装上的字，文案只用包装上印着的信息
- 配音、出片、自动挑字幕样式、配 3 版 BGM、质检

做完后交付到 `~/Movies/VideoWorkbench 成片/<日期>/<商品名>/`，里面有：

| 文件 | 说明 |
|---|---|
| `<商品名>-成片.mp4` | 主成片 |
| `<商品名>-无BGM版.mp4` | 只有配音和原声，想在抖音里配热门音乐时用 |
| `BGM备选/` | 换了 BGM 的同一条片子 |
| `手机预览/` | 720p 压缩版 |
| `封面.jpg` | 封面 |
| `发布文案.txt` | 发布时贴进简介，含 BGM 署名（如果曲子要求署名） |
| `先看这里.md` | 质检结果和素材问题 |

最后你自己在抖音上传成片、贴文案、点发布。

拍摄时注意：一定要拍到包装正面和配料表，而且字要清楚。没拍到的卖点不会出现在文案里。

## 七、Mac 上已经验证过什么，还差什么

这套流程已经在 Windows 上做过两条真成片。2026-11-09 又在 GitHub 的 Mac 云电脑（macOS 15，M1）上从零跑通：
- 装好了 CosyVoice、字体和 BGM 曲库。
- 不填 Key，用本机配音全自动出了一条完整视频，质检全部通过。
- 编码器用的是 `aac_at`，声音不破；字幕中文显示正常。

还没确认、第一次用时请顺手看一下：

1. 如果你要剪映草稿：生成的草稿能否在 Mac 版剪映里打开并正常播放。
2. Codex 从你的真素材里挑出的镜头是否合适（看成片和 `先看这里.md` 里的说明）。
3. 本机配音的速度：云电脑上 2.5 秒音频要算约 100 秒；真 M 芯片应该快一些。嫌慢就填百炼 Key，改用云端配音。

遇到问题时，把报错原文发给 Codex，并让它记进 `docs/progress.md` 的 Open 部分，方便仓库主人修复。

## 八、不会跟着仓库一起给你的东西

- 原作者的素材、成片、配音样本和剪映草稿（太大，而且有使用权限）。需要的话另外传。
- 原作者的 Key 和账号登录状态。这些每个人都要用自己的。
- BGM 和 CosyVoice 模型。它们由脚本从官方来源下载，不放在仓库里。
