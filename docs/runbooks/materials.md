# 授权素材与每日自动建片

## 默认可直接使用的路径

无需新增外部账号。打开 <http://127.0.0.1:8130/materials>，点击“同步已确认素材”，系统只会登记任务中已经勾选“拥有使用权”的视频。文件按 SHA-256 去重，复制到 `data/control-plane/licensed-library/`，并保留原任务标题、文件名和版权确认依据。

每日流程在没有 Pexels Key 时自动从该本地授权目录按主题匹配素材。内置常见宠物词归一化，例如“萌宠”“毛孩子”可匹配“宠物”素材。

## 可选：Pexels 官方 Video API

1. 在 Pexels 创建 API Key。
2. 将 Key 写入未跟踪的 `.env`：

   ```dotenv
   VIDEO_WORKBENCH_PEXELS_API_KEY=你的Key
   ```

3. 重建控制面：

   ```powershell
   docker compose -p automated-video-workbench -f deploy\compose.yml up -d --build control-plane
   ```

4. 在素材中心输入主题并点击“获取授权素材”。

系统只调用 `https://api.pexels.com/v1/videos/search`，请求竖屏 MP4；下载结果会保留 Pexels 原页、作者与许可地址。Pexels 不可用或限流时会明确警告并回退本地授权目录，不把失败伪装成官方返回。

## 每日自动任务

在首页“每日自动化”填写关键词和时间。点击“运行每日流程”可立即验证，运行记录会显示：

- 热点证据新增数；
- 素材来源和条数；
- 新建任务数量及审核入口；
- 已处理与失败任务数量；
- 外部连接缺失警告。

任务去重键是 `daily-automation:日期:关键词`。同一天重复运行不会重建相同主题；达到每次任务上限前，会跳过已完成关键词并继续尝试下一个。

## 合规边界

- 不下载、搬运抖音或小红书视频本体。
- 抖音只使用开放平台获批的视频搜索能力获取公开结构证据。
- 小红书当前只接受人工核验的公开链接证据，不绕过登录或反爬机制。
- 自动生成的成片、文案和话题必须经过审核页人工确认后才能发布。
