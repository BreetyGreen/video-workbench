# 云端余额与用量监控

控制台首页的“云端余量”同时展示两类数据：

- 火山引擎账户余额/信控、代金券、有效资源包、方舟模型免费额度与推理活动：由火山引擎只读管控面接口返回，界面标记为“官方接口”或“官方缓存”。
- ASR 音频秒数、TTS 字符/音频秒数、Dify 工作流 Token：每次任务调用后立即写入本地不可变用量账本，界面标记为“本地计量”。

## 首次配置

1. 打开 `http://127.0.0.1:8130/settings/cloud-usage`。
2. 粘贴为 `video-usage-monitor` 创建的 Access Key ID 和 Secret Access Key。
3. 如果语音赠送额度无法由官方接口识别，填写一次 ASR 总秒数和 TTS 总字符数；额度未知时可保持 0，此时只显示本地已用量并明确提示“尚未设置总额度”。
4. 保持预警线 20%、严重告警线 10%，点击“验证并保存”。

服务会先验证费用中心余额查询和方舟 `GetInferenceUsage`。只有两项均成功才保存；AK/SK 使用本机主密钥加密，接口和页面只返回 AK 掩码。不要把密钥粘贴进聊天、截图或 Git。

## 权限边界

推荐给专用 IAM 用户只授予：

- 费用中心只读：`QueryBalanceAcct`、`ListResourcePackages`、`ListCoupons`；
- 火山方舟只读：`GetInferenceUsage`、`ListModelActivations`。

不需要管理员权限，也不需要让该用户管理其他 API Key。凭证泄露时在火山引擎访问控制中禁用或删除对应 Access Key，再到设置页替换。

## 数据时效与故障降级

- 官方接口成功结果缓存 5 分钟，点击“刷新余量”会绕过缓存。
- 方舟聚合用量通常有 5–30 分钟延迟；单条视频审核页以本地逐调用账本为准。
- 官方查询失败时显示最近一次成功快照并标记“官方缓存”，不会把本地估算伪装成官方余额。
- `GetInferenceUsage` 当前只明确返回记录数量时，控制台显示“官方未返回 Token 明细”，不会把缺失字段展示为 Token `0`。
- 方舟免费额度来自 `ListModelActivations(WithFreeUsage=true)`；若账号没有有效初始额度或免费资源包，才显示“未发现”。
- 余额、方舟、资源包和代金券独立刷新；某一 Action 权限不足不会遮蔽其他成功结果。
- 任务用量明细：`GET /api/tasks/{task_id}/usage`。
