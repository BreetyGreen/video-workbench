# 全自动视频工作台收口设计

**日期：** 2026-08-21
**状态：** 已批准并进入实施
**目标：** 把当前分散的原型、验证任务和半配置能力收口为一条可重复运行的视频生产主链；凡不依赖账号本人授权的部分全部在本地实现并验证。

## 1. 产品边界

主链固定为：热点证据采集 → 选题与脚本分析 → 合规视频素材取得 → 自动剪辑与字幕/声音混音 → 人工审核 → 剪映本地草稿或抖音官方交付 → 用量与审计回写。

工作台不把未经授权的抖音、小红书视频下载为成片素材。公开网页只用于发现选题和保存可追溯的热点证据；成片只使用商家授权视频、用户上传视频、允许再使用的素材库视频或经过配置的生成视频。

## 2. 真实交付状态

系统只显示以下三种交付状态：

1. `jianying_draft`：已生成剪映本地可编辑草稿，仍需在安装剪映的 Windows 机器上打开。
2. `douyin_self_visible`：经抖音开放平台创建为仅自己可见的视频；这是已经提交审核的视频，不是客户端草稿。
3. `douyin_published`：经抖音开放平台发布并取得 `item_id`。

任何界面和 API 都不得再把官方发布接口描述为“存入抖音草稿箱”。

## 3. 素材来源与合规元数据

视频素材优先级固定为：

1. 商家授权商品视频；
2. 用户上传并确认拥有使用权的视频；
3. Pexels / Pixabay 等许可素材库视频；
4. Seedance 等生成式视频作为补充镜头。

每条可用于成片的素材必须包含：来源提供方、源链接或来源说明、商品 ID（适用时）、授权依据、允许发布的平台、授权到期时间（适用时）、文件 SHA-256、首次入库时间和使用次数。缺少授权依据的素材只能进入 `pending`，不能被自动剪辑任务选择。

## 4. 热点策略

热点来源按以下顺序聚合：

1. 已配置的抖音开放平台搜索；
2. 公开网页搜索结果的元数据证据；
3. 工作台内已审核的热点证据库。

聚合器必须记录来源、标题、链接、发现时间、关键词、证据摘要和可信度。Dify 只负责把证据结构化并生成选题/脚本建议，不负责素材版权判断或实际剪辑。

## 5. 编辑与音频策略

编辑引擎保持现有 FFmpeg 时间线架构，不在本阶段重写轨道内核。收口重点是：

- 9:16 输出，画面填充不变形；
- 字幕按语义短句切分并与旁白时间对齐；
- 字幕样式采用高对比、手机安全区、关键词强调；
- 原视频有人声时自动降低或跳过旁白，环境声保留；
- 原视频只有环境音时使用旁白并自动闪避背景声；
- 任务详情页显示声音决策、字幕覆盖率和质量检查结果。

## 6. 项目恢复和任务卫生

现存验证任务不删除，统一进入可恢复的归档状态。默认任务列表隐藏归档任务，并提供“查看归档”和“恢复”入口。每日自动任务、生产任务和验证任务必须可区分。

后台调度器必须在测试环境显式关闭，避免测试夹具与真实每日任务同时写入临时产物目录。项目根目录补充恢复说明，进度文档顶端必须清晰列出 Outcome、Confirmed、Open 和 Next Action。

## 7. 部署边界

服务端部署包含控制台、数据库、对象存储/文件存储、Dify（若需要远程工作流）和定时任务。剪映草稿生成器保留在本地 Windows 机器；服务器通过任务状态等待本地代理取走草稿任务。

部署包必须提供环境变量样例、健康检查、持久化卷、日志轮转、数据库备份与恢复步骤。没有服务器地址、SSH 权限和域名时，只完成可直接部署的包和运行手册，不虚构线上已部署状态。

## 8. 必须由用户本人完成的动作

以下动作涉及购买、账号身份或 OAuth 同意，系统只能提供入口和诊断：

- 购买或指定火山引擎云服务器，并提供可用的 SSH 目标；
- 在抖音开放平台创建应用、申请发布/搜索权限并完成用户 OAuth；
- 在抖店开放平台完成店铺或供应商授权，取得商品素材访问权限；
- 为 Pexels、Pixabay、Seedance 填入所选服务的合法凭证和模型/端点；
- 若使用域名，完成 DNS 解析和必要的备案/证书流程。

除上述动作外，项目恢复、代码实现、测试、界面收口、配置诊断和部署脚本均由本阶段完成。

## 9. 验收标准

- 全量自动化测试无失败，调度器测试无目录竞争。
- 默认任务列表不再混入历史验证任务；归档任务可恢复。
- 上传授权视频能够入库、被选择、生成预览并记录完整来源审计。
- Pexels/Pixabay 任一配置后能够搜索并下载许可视频；未配置时显示准确原因。
- 热点聚合在官方搜索不可用时能够使用公开证据或已审核证据，不下载平台视频。
- 生成的视频通过字幕、旁白覆盖、画面比例和音频路由检查。
- 剪映草稿、抖音仅自己可见和抖音发布三个状态在界面/API 中语义一致。
- 部署配置能够在新的服务器上以一条启动命令运行，并有备份恢复手册。
