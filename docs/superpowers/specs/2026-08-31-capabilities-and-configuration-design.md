# 能力与配置说明体系设计

## 背景

仓库已经具备本地优先的视频生产主链和多种可选外部服务，但能力说明分散在 README、运行手册、配置助手和多个专题文档中。普通用户难以判断“剪辑是否必须填写 Key”，Codex 也缺少一份可以直接据此启动、诊断和解释降级路径的统一事实源。

## 目标

1. 新用户 clone 后首先明确：本地上传、分析、自动剪辑、字幕、预览、质检和剪映草稿不需要云端 Key。
2. 每项能力统一标注为“零配置本地能力”“可选增强”或“外部授权能力”。
3. 对每个外部服务说明用途、所需配置、配置入口、未配置时的行为、数据是否离开本机和验收方法。
4. 普通用户从 README 和能力手册理解系统；Codex 从 `AGENTS.md` 和机器可读清单获得相同事实。
5. 配置助手直接展示能力分级与降级路径，不再只展示供应商名称。

## 非目标

- 不把维护者凭据写入仓库，不自动读取剪贴板或要求用户在聊天中发送秘密。
- 不把抖音审批、OAuth、系统权限或剪映首次打开伪装成自动配置。
- 不改变剪辑算法、供应商接口或发布权限边界。
- 不承诺剪映 7+ 自动导出；本次仍以生成和安全导入可编辑草稿为边界。

## 方案比较

### 方案 A：只扩充 README

改动最小，但信息仍会随着配置项增长而失真，应用内也无法解释当前状态。

### 方案 B：文档和配置助手分别维护

用户体验较好，但同一事实存在两套副本，容易出现“文档说可选、界面像必填”的漂移。

### 方案 C：统一能力清单，文档与界面围绕同一分类组织（采用）

由后端返回结构化能力清单，配置助手按清单展示；仓库同时提供人类手册和 Codex 操作指南。自动测试验证关键能力、Key 分类和秘密不外泄。该方案改动适中，但最能保证 clone 后的可理解性和长期一致性。

## 能力分级

### 零配置本地能力

- 本地视频上传与授权登记
- FFmpeg/FFprobe 媒体探测、场景、静音和关键帧分析
- RapidOCR 画面文字识别
- 本地 Whisper 转写（预览 `small`，正式 `large-v3`）
- 高光选段、镜头交替、9:16 排版、字幕、音量标准化、封面、MP4
- 黑场、静音、时长、画布、时间线、字幕和旁白覆盖质量门禁
- 剪映草稿 ZIP；检测到本机草稿目录后可安全导入新草稿

### 可选增强

- 火山 BigASR：正式任务经用户允许后优先云端转写；失败回退本地 `large-v3`
- 火山 TTS：生成云端旁白；不可用时保留原始音轨继续处理
- Dify：教程拆解和爆款分析；不可用时使用本地策略和候选文案
- Pexels/Pixabay：搜索有来源记录的公共素材；不可用时使用用户上传和本地授权素材
- Seedance：按明确请求生成 9:16 素材；不可用时不自动付费生成
- 火山只读用量：展示官方余额/用量；不影响剪辑

### 外部授权能力

- 抖音官方搜索：需要应用凭据、Device ID 和获批接口权限
- 抖音发布：需要应用权限与发布账号 OAuth；本地剪映草稿不依赖它
- 钉钉素材入口：需要组织应用/机器人授权；本地上传不依赖它
- 服务器、域名和 HTTPS：只影响远程访问，不影响本机运行

## 文档结构

- `README.md`：clone、零 Key 结论、三档能力总览和文档入口。
- `docs/capabilities-and-configuration.md`：面向普通用户的完整能力与配置矩阵。
- `docs/codex-operator-guide.md`：面向 Codex 的启动、诊断、配置决策、秘密处理和验收顺序。
- `AGENTS.md`：短而强制的代理规则，并链接到 Codex 指南。
- `.env.example`：按类别分组并标注可选性，不含真实值。
- `docs/user-required-actions.md`：仅保留账号本人必须完成的授权动作，并链接能力手册。

## 应用内呈现

配置助手增加“能力说明”区：

- 首屏明确显示“本地剪辑：无需 Key”。
- 以三种徽标区分“无需 Key”“可选增强”“需要外部授权”。
- 每项显示支持功能、所需配置、未配置时行为和数据边界。
- 外部服务卡仍保留实时连接状态、官方入口和重新检测。
- 页面不返回或显示任何真实 Key、Secret、Token 或 AK/SK。

## 验证

1. 服务测试验证本地能力与三档分类完整。
2. API 测试验证返回中不出现凭据值或秘密字段名。
3. 页面测试验证“无需 Key”、能力矩阵和文档入口存在。
4. JavaScript 语法检查。
5. 全量 Python 测试。
6. fresh-clone 验证器确认无 `.env`、无云端 Key 时仍可进入本地模式。
