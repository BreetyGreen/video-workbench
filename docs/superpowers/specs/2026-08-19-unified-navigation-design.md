# 视频生产控制台统一导航设计

## 目标

消除工作台、云端余量设置和任务审核三类页面之间的割裂感，让用户在任一页面都能明确返回工作台，并能直接进入余量设置或当前审核上下文。

## 采用方案

采用统一顶部导航。三个页面共享同一套品牌、主导航与当前页面状态，不引入侧边栏，也不依赖浏览器历史记录。

## 页面结构

- 工作台：顶部显示品牌、工作台（当前）、云端余量、API 文档、ArcReel。
- 云端余量设置：顶部显示品牌、工作台、云端余量（当前）、API 文档；页面标题区保留“返回工作台”按钮。
- 任务审核：顶部显示品牌、工作台、云端余量、任务审核（当前）；页面标题区提供“返回工作台”。
- 移动端：保留工作台和云端余量两个核心入口；次要外部入口允许折叠或隐藏。

## Access Key 引导

云端余量设置页增加一张固定说明卡：

1. 进入火山引擎“用户管理 → 用户”。
2. 点击 `video-usage-monitor` 用户名。
3. 进入“密钥”页签，使用该子用户已有的 Access Key。
4. 分别复制 Access Key ID 与 Secret Access Key；不要创建下方的 API Key。
5. 若 Secret Access Key 已无法再次查看，提示用户执行密钥轮换，而不是改用主账号密钥。

说明卡只提供指导，不读取或展示云端密钥。

## 实现边界

- 新增一个 Jinja 导航片段和一份共享导航样式，三个模板复用。
- 不改变任务、审核、凭证保存或云端查询 API。
- 不加入浏览器 `history.back()`；所有返回链接都指向确定的 `/`。

## 验证

- 模板测试检查三个页面均包含工作台和云端余量入口。
- 设置页测试检查 Access Key 指引、`video-usage-monitor` 和“不要创建 API Key”提示。
- 桌面与移动宽度检查导航不会遮挡页面内容。
- 部署后对 `/`、`/settings/cloud-usage` 和任务审核页执行 HTTP 冒烟检查。
