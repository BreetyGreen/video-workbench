# 智能剪辑引擎设计

## 背景与目标

现有工作台已经能保存素材、调用 Dify、生成单素材预览与剪映草稿，但剪辑效果仍停留在“取第一个视频、裁到目标时长、放一条标题”。本阶段把它升级为可日常使用的本地短视频剪辑引擎：理解全部素材，去掉明显停顿，选择高信息密度片段，生成统一的多素材时间线，并从同一时间线输出竖屏 MP4、自动字幕、封面和可编辑剪映草稿。

完成标准不是“接口存在”，而是一个含两段以上素材与真实语音的样例任务能够产生可播放成片；成片包含来自多个源文件的片段、与语音时间对齐的字幕、规范化音量、竖屏构图和封面，剪映草稿必须包含同样的片段顺序与字幕文本。

## 方案选择

### 方案 A：全部交给云端剪辑产品

接入快，但素材上传、成本、接口稳定性与时间线可追溯性不可控，也不能保证输出能在本机剪映继续编辑，因此不采用。

### 方案 B：纯生成式模型决定并渲染全部内容

创意上限高，但结果不稳定、很难精确复现，且在模型不可用时整条链路失效，因此不采用。

### 方案 C：本地确定性引擎 + 可选语义模型

采用此方案。faster-whisper、FFmpeg、RapidOCR 和确定性规划器构成始终可运行的本地核心；Dify 在配置后读取转写、OCR 与画面指标，补充教程语义和趋势策略。模型只输出受类型约束的建议，最终裁切点、轨道、时长与渲染由本地代码验证。

## 输出规格

- 默认画布：1080×1920、30fps、H.264、AAC、`yuv420p`、faststart。
- 默认成片时长：30 秒；教程配方可调整，但自动模式最多 180 秒且不超过有效素材总长。
- 音量：社交视频目标 -14 LUFS，True Peak 不高于 -1.5 dB。
- 字幕：使用转写时间戳，最多两行，位于竖屏安全区；输出 `captions.ass`、`captions.srt`，并写入剪映文字轨。
- 横屏素材：使用模糊铺满背景与等比前景，不用黑边；竖屏素材等比裁切至画布。
- 封面：从最高评分片段抽取清晰帧，加标题与安全区排版，输出 1080×1920 JPEG。
- 审核证据：保存每段素材的转写、场景、静音、OCR、画面指标、入选原因和最终时间线。

## 媒体理解

### 转写

使用 `faster-whisper 1.2.1`，默认 `small` 模型、CPU `int8`、自动语言识别和词级时间戳。模型缓存在持久化目录。无音轨、纯音乐或模型暂不可用时不伪造字幕，而是留下明确警告并继续视觉剪辑。

### 场景与静音

FFmpeg 场景检测产生镜头边界；`silencedetect` 产生静音区间。说话类素材优先保留转写片段并在句首句尾各留 150ms，连续静音超过 800ms 的部分从候选时间线移除。无语音素材按场景边界切成 1.2–4.5 秒候选段。

### 关键帧、OCR 与画面质量

每个场景抽取代表帧。RapidOCR 读取画面已有文字；本地指标记录亮度、对比度、清晰度、分辨率和场景变化强度。OCR 结果只用于避免重复字幕覆盖原画面文字和给 Dify 提供可追溯描述，不推断人物身份或事件。

## 时间线规划

新增唯一权威的 `EditingTimeline`：

- `clips`：源素材、源入点/出点、时间线入点、评分和入选原因。
- `captions`：时间线字幕文本、起止时间和源转写引用。
- `audio`：原声增益、可选 BGM、混音与响度目标。
- `cover`：来源片段、抽帧时间和标题。
- `quality`：目标时长、画布、转场和字幕样式。

规划器先建立全部候选段，再按教程节奏选择：首段从前 8 秒候选中选语音/运动/清晰度综合最高者；正文轮换不同素材，避免连续使用同一源文件；快节奏片段 1.2–3 秒，叙述片段按完整句子保留但不超过 6 秒；不足目标时长时按剩余评分补齐，不循环复制同一段。

Dify 配方影响目标时长、钩子、节奏和禁用元素，但任何超出素材范围、重叠或小于 300ms 的片段都会被本地验证器拒绝或修正。

## 渲染与剪映同步

FFmpeg 读取 `EditingTimeline`，对每段执行 trim、纵向构图、有限度颜色校正和拼接；原声先归一化，若用户上传独立音频则作为 BGM 循环并以低音量混合，语音期间自动压低。字幕通过 ASS 烧录到预览，同时保留独立文件。

剪映适配器读取相同时间线，为每个片段设置对应 `source_timerange`，生成逐条字幕轨和可选 BGM 轨。预览与草稿不得分别生成另一套顺序或时长。

## 工作台与审核

任务审核页新增“理解结果”和“编辑时间线”：展示素材数、语言、转写片段数、被删除静音时长、镜头数、最终片段顺序及入选原因；提供字幕和时间线 JSON 下载。工作台任务行显示“本地智能剪辑”或“Dify 增强”标识。

## 错误处理与隐私

- 原始素材只读，不移动、不删除、不覆盖。
- 单个素材分析失败时记录素材级错误；仍有有效视频时继续任务，没有有效视频时任务失败。
- 模型下载与缓存目录持久化；错误信息不得包含密钥、完整转写或本地私密路径。
- 自动生成内容继续经过版权、交付物和人工审核门禁。
- 不自动生成或下载 BGM；只有用户上传并确认权利的音频才进入时间线。

## 验证

1. 单元测试证明静音区间取反、候选段裁剪、片段轮换、字幕重映射与时间线边界校验。
2. FFmpeg 集成测试用不同宽高比和音轨状态的两个合成视频，证明输出为 1080×1920、包含音视频流且时长匹配时间线。
3. 转写适配器测试验证真实词级时间戳；容器端到端验收使用本地合成语音样例，不只使用 mock。
4. 草稿 ZIP 检查多个视频片段、字幕条数、源入点和时间线时长与 `edit-timeline.json` 一致。
5. 审核页与下载接口验证分析、字幕、封面和时间线交付物。

## 非目标

- 不识别人脸身份，不基于敏感属性评分。
- 不承诺模型能理解所有幽默、情绪或剧情；低置信度内容在审核页提示人工调整。
- 不使用浏览器 Cookie 自动发布抖音。
